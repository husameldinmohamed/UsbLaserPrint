# طباعة USB — HP Laser MFP 135a

تطبيق أندرويد بيطبع على طابعات **HP Laser MFP 13x** (135a / 135w / 137fnw) مباشرة بكابل USB ووصلة OTG، من غير كمبيوتر ومن غير تعريفات.

## المميزات
- طباعة ملفات PDF والصور (وكمان من زرار "مشاركة" في أي تطبيق)
- اختيار صفحات معينة: `1-3, 5, 8-`
- عدد النسخ
- وش وضهر يدوي: بيطبع الوش، وبعدين يقولك تقلب الورق ويطبع الضهر
- مقاسات الورق A4 وA5 وB5 وLetter وLegal وOficio
- جودة 600 أو 1200 DPI، وغمق الحبر، وتوفير الحبر

## إزاي بيشتغل
الطابعة دي ما بتفهمش غير لغة **SPL/QPDL** بتاعة Samsung. التطبيق بيحوّل كل صفحة لصورة أبيض وأسود،
ويضغطها بخوارزمية 0x11، ويبعتها في أوامر QPDL v3. الجزء ده متنقل من مشروع
[SpliX](https://github.com/OpenPrinting/splix) (الإصدار 2.0.2)، واتأكدنا إن الناتج متطابق بايت ببايت مع `rastertoqpdl` بتاع SpliX.

## البناء
- كل push على `main` بيبني الـ APK في GitHub Actions، وبينزل في Release اسمه **latest**.
- أو افتح المشروع في Android Studio ودوس Run.
